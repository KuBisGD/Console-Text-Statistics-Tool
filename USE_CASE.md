# Use Cases

- Get statistics form a given text
- Console UI to navigate options


## Get text

 - User should be able to load a text by entering it **line by line**.
 - User should be able to load a text by providing a file path.

## Get text statistics

 - User should be able to get:
    - Character count
    - Word count
    - Sentence count
    - Amount of time every word apers
    - Length of average word
    - Length of average sentence
    - How long the text would take to read based on a words per minute count

## Persistent data

 - User should be able to save a loaded text to a predetermined folder
 - Uses should be able to pick the name of the saved file.
 - User should be able to see saved files and load them.
